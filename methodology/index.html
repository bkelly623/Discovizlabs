Method

How we measure what models cite—and improve what they understand.

“Methodology” is just our repeatable measurement protocol: a fixed prompt set, consistent scoring, and a weekly ship loop. If we can’t measure it, we don’t claim it.

Core KPI: Share of Answer

Across a fixed set of buyer prompts, we track how often AI systems reference the client: brand name, product, URL, or a direct citation of their core claim.

Weekly loop

  1. Run the same prompt set in multiple AI systems.
  2. Record citations and the wording used.
  3. Ship 3 focused fixes (pages, clarity, citations).
  4. Re-measure next week.
